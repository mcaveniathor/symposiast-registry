# Enable only the component groups used by the shell

Use default-features = false with layout, typography, and forms for this recipe. The facade enables forms dependencies automatically; do not enable axum merely to export a static page. Field provides the label and Input provides the explicit control ID used by application code.

Basis: Documented.

Features: layout, typography, forms.
