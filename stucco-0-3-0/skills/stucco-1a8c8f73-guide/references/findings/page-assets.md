# Deliver assets with rendered HTML

Compose a Bundle and Page, using main for a landmark and skip link or app for an AppShell. Default output references assets under /_stucco/: serve the bundle or export its files alongside static pages. Delivery::Inline embeds the required assets for standalone output, but inline pages cannot receive fragments.

Basis: Documented.

Features: No additional features stated.
